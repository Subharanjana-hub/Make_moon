# ANN - Binary Classification Using the make_moons Dataset

An Artificial Neural Network built with TensorFlow and Keras that performs binary classification on the `make_moons` dataset from Scikit-learn.

## About the Project

The `make_moons` dataset creates two interleaving half-circles, one for each class. The two classes cannot be separated by a straight line, so this is a good test for a neural network. The project generates 1000 data points, trains an ANN to tell the two moons apart, and plots the curved decision boundary the network learns.

## Features

- Dataset generated with `make_moons` (1000 samples, noise 0.2)
- Stratified split into training, validation and test sets
- Feature scaling with StandardScaler
- ANN with three hidden layers, Dropout and a sigmoid output
- Callbacks: EarlyStopping and ReduceLROnPlateau
- Training curves for accuracy and loss
- Evaluation with a classification report, confusion matrix and ROC curve
- Decision boundary plot
- Saves the trained model and reloads it to classify a new point

## Model Architecture

| Layer | Details |
|-------|---------|
| Input | 2 features |
| Hidden 1 | Dense (32), ReLU, Dropout 0.1 |
| Hidden 2 | Dense (16), ReLU, Dropout 0.1 |
| Hidden 3 | Dense (8), ReLU |
| Output | Dense (1), sigmoid |
| Loss | Binary cross-entropy |
| Optimizer | Adam (learning rate 0.01) |

## Requirements

- Python 3.9 or higher
- TensorFlow
- NumPy
- Matplotlib
- scikit-learn

Install everything with:

```bash
pip install tensorflow numpy matplotlib scikit-learn
```

## Usage

```bash
python ann_make_moons.py
```

No dataset download is needed because the data is generated by the script. You can change `N_SAMPLES` and `NOISE` at the top of the script to make the problem easier or harder.

## Output

All results are saved in the `ann_moons_outputs/` folder:

| File | Description |
|------|-------------|
| `dataset.png` | The make_moons data points |
| `training_curves.png` | Accuracy and loss over epochs |
| `confusion_matrix.png` | Confusion matrix on the test set |
| `roc_curve.png` | ROC curve with AUC score |
| `decision_boundary.png` | Boundary learned by the network |
| `ann_moons.keras` | Trained model |
